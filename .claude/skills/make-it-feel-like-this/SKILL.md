# Make it feel like this

A reference screenshot is a mood, not a spec. Never copy it.

1. Describe what makes it feel the way it does, in 5 lines max: density, type scale and weight contrast, color temperature and where color is spent, border/shadow strategy, spacing rhythm, motion if visible.
2. Diff that against the current screen and the design-system skill. Name the 2–3 changes that would move us 80% of the way.
3. Check the design-system skill: if the reference contradicts a stated taste (e.g. vertical grid lines, heavy grotesk headlines, grey rounded template cards), say so in one line and skip that part.
4. Apply as a single diff. Show before/after screenshots.
5. If the change is a pattern (not one screen), add one line to the design-system skill so it sticks.

Never reproduce the reference's logo, wordmark, product name, illustrations, or copy.
