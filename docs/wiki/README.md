# Wiki

Git-backed markdown memory for the agents (and Shireen). Plain files, [[wikilinks]] welcome, compatible with Obsidian and with `akitaonrails/ai-memory` (`ai-memory init --data-dir docs/wiki`).

- `../decisions.md` — architectural decisions (already the canonical log; not duplicated here)
- `mistakes.md` — every agent mistake and where its fix landed (see mistake-to-skill skill)
- `glossary.md` — shared language (grill-with-docs writes here)
- `competitors.md` — weekly competitor-watch output
- `log/` — nightly 5-line logs per agent session
- `funnel/` — 7am funnel reviews
- `churn/` — Monday cancellation digests
